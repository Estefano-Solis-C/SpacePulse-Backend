# SpacePulse Backend

API RESTful basada en Domain-Driven Design (DDD) y CQRS (MediatR) con .NET 8.

## Inicio Rapido

```bash
cd RentalPeAPI
dotnet restore
dotnet run
```

API disponible en: http://localhost:5000/

git init
